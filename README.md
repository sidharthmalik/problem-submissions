| Source | Folder | How it's added |

## NeetCode auto-sync

NeetCode folders are populated automatically through NeetCode's GitHub Sync, so I don't edit them by hand.

- **Auto-commit:** every submission on NeetCode is pushed here (configurable by status).
- **Bulk sync:** past solutions can be pushed all at once from neetcode.io/profile/github.
- **Manual sync:** individual submissions can be synced or removed from the problem page.
- **File layout:** `<topic-folder>/<problem-id>/submission-N.<ext>`, one file per submission.

Supported languages: Python, JavaScript, TypeScript, Java, C++, C#, Go, Rust, Kotlin, Swift, SQL.

## LeetCode and other sites
